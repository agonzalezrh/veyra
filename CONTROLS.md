# Veyra Controls — Quick Reference

## Camera — on empty space

| Input | Effect |
|---|---|
| **Wheel** | Approach / back away (toward the pointer) |
| **Left-drag** | Move the world (pan) |
| **Right-drag** | Look around (orbit) |
| **Home** | Show the whole desktop — recovery from anywhere |

## Windows

| Input | Effect |
|---|---|
| **Click** | Focus |
| **Left-drag** | The application's content (select text, sliders) |
| **Alt+drag** or **Meta+drag** | Move the window |
| **Right-drag** | Rotate the window |
| **Right-click** (no drag) | Actions menu |
| **Wheel** | Scroll the application |

## Taskbar (bottom edge)

| Action | Effect |
|---|---|
| Click a window button | Focus it (travels across workspaces) |
| Click the focused button | Minimize / restore |
| Click `1 2 3` | Switch workspace |
| Hover a window button | Lights that window in the scene |
| `+N` | Activate the oldest hidden window |

## Keyboard

| Key | Effect |
|---|---|
| `Home` | Show the desktop |
| `F5` | Toggle spatial mode |
| `F6` | Focus mode |
| `Esc` | Close menus / release grabs |
| `F7` / `F8` | Next / previous window (MRU) |

## Windows (the OS kind)

- Ordinary Wayland and X11 applications run unmodified.
- Popups, bubbles and menus (chrome-style floats) render and are clickable.
- Clipboard, drag & drop and text input work across both.
